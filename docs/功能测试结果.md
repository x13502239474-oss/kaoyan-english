## 五、开发中发现并修复的真实缺陷

| # | 问题 | 影响 | 修复 |
|---|---|---|---|
| 1 | `ui.js` 只导出散装函数，视图层用 `import { ui }` | **全站模块加载失败** | 增加命名空间汇总导出 `export const ui = {...}` |
| 2 | `openSheet` 先关闭弹层再执行回调 | 弹层内表单（编辑词条、人工自评）读到空值，保存失败 | 改为**先执行回调并传入弹层元素、再关闭**，且用 `try/finally` 兜底 |
| 3 | `words.js` 三个 action 回调参数顺序错误 / 未触发刷新 / 搜索容器缺失 | 显隐释义、掌握标记、搜索无响应 | 修正签名为 `(el, ctx)` 并补 `ctx.refresh()` 与局部刷新容器 |
| 4 | `practice.js` 单引号字符串里写了 `${}` 插值 | 素材数量显示为字面量 | 改为模板字符串 |
| 5 | `cloze.js` 从 `location.hash` 字符串猜试卷 id | 路由带查询参数时可能取错 | 改用 `ctx.params[0]` |
| 6 | `srs.js` 用 `toLocaleDateString('sv-SE')` 取当天 | 依赖 ICU，跨环境不稳定 | 改用统一的 `utils.today()` |
| 7 | store 缺 `drafts` / `wordTests` / `customArticles` 字段 | 练习草稿、单词测试成绩、导入文章无处可存 | 补齐字段并纳入 migrate / 合并恢复 |
| 8 | 「批量导入阅读文章」只有按钮没有落点 | 会成为空壳功能 | reading.js 接入 `customArticles`，导入后可列表查看与逐题练习 |

> 测试脚本自身也修正了 3 处断言（Node 22 只读 `navigator`、测试用例使用了词库中不存在的词、刷新后路由断言写死），这些不是产品缺陷。

## 六、已知边界（如实说明）

- **发音**：无头 Chrome 无音频设备，自动化测试只能验证 `speechSynthesis` API 调用链路与降级提示；请在手机或电脑浏览器点一次「朗读单词」确认实际发声。
- **主观题**：翻译与写作按需求提供参考答案 / 范文与人工自评，网站不做自动评分，也不宣称评分准确。
- **内容**：全部内置题库为演示/AI 生成示例，不含真题；资料词形清单可能残留 OCR 噪声，且没有音标与释义。
- **同步**：按需求不做云端与跨设备同步，数据只在当前浏览器。
