# 数据备份与恢复说明

## 一、数据存在哪里

所有学习数据保存在**当前浏览器的 localStorage**，键名：

```
ky-english-state-v1
```

包含：单词掌握记录与熟练度、收藏生词、自定义/导入词条、课程笔记与完成状态、阅读/完形/单词测试成绩、翻译历史、作文草稿与自评、考试进行中答卷与历史成绩、错题本、学习记录、每日目标完成量、设置。

**不包含**：内置静态词库、文章、题目、课程、试卷——这些是项目 `data/` 目录里的代码文件，本来就在硬盘上，不需要备份。

刷新、关闭浏览器、关机后数据不会丢失。Service Worker 缓存应用外壳，断网也能打开已加载过的页面。

### 什么情况下数据会「不见」

| 情况 | 说明 |
|---|---|
| 清除浏览器数据 / 站点数据 / Cookie | 会一并清掉 localStorage，**不可恢复** |
| 换浏览器、换设备、换电脑 | 数据不跨设备，新环境是空的 |
| 无痕 / 隐私模式 | 关闭窗口后数据被清除 |
| 浏览器存储被禁用 | 网站会提示「存储不可用，请及时导出备份」，此时数据只在内存里 |
| 删除站点 PWA / 站点数据 | 数据一并清除 |

> 因此：**定期导出 JSON 备份是唯一可靠的保险**。建议每周一次，或每次大量录入后导出，存到网盘/邮箱/移动硬盘。

## 二、导出备份

1. 打开网站 → 右上角齿轮 或 底部进入「统计 → 数据管理」→ **数据与设置**；
2. 找到「备份与恢复」→ 点 **导出**；
3. 浏览器会下载一个文件，例如：

```
英语二-学习数据备份-20261107-1930.json
```

文件内容结构（可自行用文本编辑器查看）：

```json
{
  "app": "kaoyan-english-selfstudy",
  "version": 1,
  "exportedAt": "2026-11-07T11:30:00.000Z",
  "note": "考研英语二自学网站 · 本地学习数据备份（不含内置静态词库与题库）",
  "state": { "wordProgress": {}, "essays": [], "mistakes": [], ... }
}
```

---

## 三、恢复备份

1. 进入 **数据与设置 → 备份与恢复**；
2. 先在下拉框选择恢复模式：
   - **覆盖当前数据**：用备份完整替换现有数据（适合换新设备、数据错乱后回滚）；
   - **与当前数据合并**：保留双方记录，数组按 id 去重；单词进度取较熟练的一方并累加次数（适合两台设备轮流使用后的合并）。
3. 点「选择备份文件」，选中此前导出的 `.json`；
4. 弹层会显示备份时间与记录条数，确认后点 **确认恢复**；
5. 页面自动重新加载，数据即刻生效。

**安全校验**：恢复前会检查 `app` 标识、必要字段与 JSON 合法性；来自其他应用的文件、非法 JSON、结构不符的文件会被拒绝并给出提示，不会污染现有数据。

> ⚠️「覆盖」不可撤销。执行前建议先点一次「导出」，把当前状态也存一份。

---

## 四、重置数据

「数据与设置 → 重置全部学习数据」会清空所有进度与记录，**不可撤销**，需要二次确认。重置前请先导出备份。

---

## 五、换设备 / 换浏览器的完整流程

1. 旧设备：数据与设置 → 导出，得到 JSON 文件；
2. 把文件传到新设备（网盘、微信文件传输助手、U 盘均可）；
3. 新设备：用 `启动.bat` 启动本网站（项目文件夹需一并拷贝，或在同一台机器上换浏览器）；
4. 数据与设置 → 选择备份文件 → 覆盖恢复。

> 注意：localStorage 按「浏览器 + 域名/端口」隔离。若新设备访问端口不同（例如 5184 变成 5185），数据仍是独立的，需要走恢复流程。这也是建议用备份文件而不是依赖浏览器存储的原因。

## 六、开发者补充（可选）

在浏览器开发者工具 Console 里可以直接查看原始状态：

```js
JSON.parse(localStorage.getItem('ky-english-state-v1'))
```

也可以调用内置模块做程序化备份/恢复：

```js
const s = await import('./js/store.js');
const backup = s.exportBundle();      // 导出字符串
s.parseBundle(backup);                 // 校验
s.restore(backup, 'replace');          // 恢复（'replace' | 'merge'）
```

`tools/smoke-test.js` 已对这些路径做了自动化覆盖：导出结构校验、拒绝其他应用、覆盖恢复、合并恢复、重置后恢复。
