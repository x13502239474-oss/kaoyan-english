# 批量导入说明

所有导入入口都在 **数据与设置 → 批量导入内容**。导入的内容归你所有，界面会标注为「用户导入」，不会伪装成官方数据。

> 请只导入你拥有使用权的材料。本站不提供、也不内置任何历年真题与官方答案。

---

## 一、导入词汇表（立即生效）

支持两种格式，粘贴到「① 词汇表」文本框，或点「选择 .txt/.json 文件」载入后点 **导入到词库**。

### 格式 A：纯文本，每行一条

```
单词,音标,词性,中文释义
abandon,/əˈbændən/,v.,放弃；抛弃
sustain,/səˈsteɪn/,v.,维持；支撑
```

分隔符支持英文逗号 `,`、中文逗号 `，`、制表符 `\t`。音标与词性可留空，但顺序需保留：

```
zoom,,,快速上升
```

### 格式 B：JSON 数组

```json
[
  {
    "word": "abandon",
    "phonetic": "/əˈbændən/",
    "pos": "v.",
    "meaning": "放弃；抛弃",
    "example": "The board decided to abandon the plan.",
    "exampleZh": "董事会决定放弃该计划。",
    "collocations": ["abandon oneself to 沉溺于", "with abandon 尽情地"],
    "rare": "n. 放纵",
    "tier": "high",
    "tags": ["阅读"]
  }
]
```

也支持 `{ "words": [ ... ] }` 包装形式。

| 字段 | 必填 | 说明 |
|---|---|---|
| `word` | 是 | 英文词形（自动转小写） |
| `phonetic` | 否 | 音标，支持 IPA 字符 |
| `pos` | 否 | 词性，如 `v.` / `n.` / `a.` |
| `meaning` | 否 | 中文释义（**建议必填**，否则卡片会提示补全） |
| `example` / `exampleZh` | 否 | 英文例句与中文对照，都可发音 |
| `collocations` | 否 | 常见搭配数组 |
| `rare` | 否 | 熟词僻义 |
| `tier` | 否 | `high` / `mid` / `low`，用于词频分类 |
| `tags` | 否 | 标签数组 |

**同名覆盖**：导入的词若与内置演示词条同名，会优先显示你导入的版本（可在单词卡片点「编辑词条」再修改）。导入后立即出现在「单词 → 词表 → 我导入/编辑的词」。

## 二、导入阅读文章 + 题目 + 答案解析（立即生效）

粘贴含 `articles` 数组的 JSON 到「② 阅读文章」文本框，点 **导入文章**。导入后会出现在「阅读理解」列表，标注「用户导入」，可完整使用段落编号、生词标注、长难句、结构分析、逐题练习、定位解析与错题归档。

```json
{
  "articles": [
    {
      "id": "my-r1",
      "title": "My Own Reading Passage",
      "topic": "自定义",
      "level": "用户导入",
      "minutes": 10,
      "paragraphs": [
        { "no": 1, "text": "Paste the first paragraph here." },
        { "no": 2, "text": "Paste the second paragraph here." }
      ],
      "gloss": [
        { "word": "paragraph", "phonetic": "/ˈpærəɡrɑːf/", "meaning": "n. 段落", "para": 1 }
      ],
      "sentences": [
        { "para": 1, "text": "Paste the first paragraph here.", "split": "主干：…", "note": "提示：…" }
      ],
      "structure": {
        "thesis": "一句话主旨",
        "outline": ["第1段：…", "第2段：…"],
        "tone": "客观说明"
      },
      "questions": [
        {
          "id": "my-r1q1",
          "type": "single",
          "tag": "细节题",
          "stem": "What does the first paragraph say?",
          "options": ["选项 A", "选项 B", "选项 C", "选项 D"]
        }
      ],
      "answerKeys": {
        "my-r1q1": {
          "answer": 0,
          "location": "第 1 段第 1 句",
          "knowledge": "细节定位",
          "correct": "正确选项的理由…",
          "wrong": ["A 错在…", "C 错在…", "D 错在…"]
        }
      }
    }
  ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一标识，重复导入会覆盖同 id 文章 |
| `title` | 是 | 列表标题 |
| `paragraphs` | 是 | 段落数组，`no` 为段号，`text` 为英文正文 |
| `questions` | 否 | 题目数组，含 `id` / `stem` / `options`（4 项）/ `tag` |
| `answerKeys` | 否 | 以题目 id 为键；`answer` 是 0–3 的选项索引 |
| `gloss` / `sentences` / `structure` | 否 | 生词标注 / 长难句拆解 / 结构与主旨，可省略 |

**结构分离**：文章正文、题目、答案解析在导入数据里也是分开的三个部分，与内置数据层设计一致。

## 三、下载模板

点「下载模板」会得到 `英语二-批量导入模板.json`，内含：
- 2 条示例词条（完整字段）；
- 1 篇示例阅读文章（含题目与答案解析）；
- `courses` / `examPapers` 的**字段结构示例**（预留）。

## 四、课程与试卷的导入（预留说明）

`data/` 目录已经把课程、文章、题目、答案解析、试卷各自作为独立模块存储，新增内容不需要改界面代码。模板里也给出了 `courses` / `examPapers` 的字段形状。

当前版本**只让 `words` 与 `articles` 两类导入真实生效**——这是刻意的设计：不放置「点了没反应」的按钮。若后续要扩展，按现有 `data/courses.js`、`data/exams.js` 的结构补充读取逻辑即可，界面无需重构。

按题型分类练习已从现有题库抽题生成限时小测（客观题自动评分）；翻译/写作/词汇专项会跳转到对应训练模块。
