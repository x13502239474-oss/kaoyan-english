# 考研英语二 · 个人自学工作台

一个**零依赖、手机优先、数据全部保存在本机**的个人学习网站。包含单词间隔复习、阅读理解、完形填空、翻译、写作、课程、模拟考试、错题本与学习统计。

> ⚠️ **重要内容声明**：本站**不含任何历年考研英语二真题、官方答案或权威词汇数据**。内置文章、题目、课程、范文、试卷均为**演示内容 / AI 生成示例**，界面已逐处标注。词形清单来自你提供的 docx 自动抽取（仅词形与年份，无音标释义，可能含 OCR 噪声）。请勿把演示内容当作备考依据；正式材料请用「设置 → 批量导入」自行导入。

## 一、启动（最简单的一种）

**Windows 用户：直接双击项目目录里的 `启动.bat`**。会弹出一个黑色窗口，显示访问地址，别关它（关了网站就停了）。

```
✅ 考研英语二自学网站已启动
➜ 电脑访问:  http://localhost:5184/
➜ 手机访问:  http://192.168.x.x:5184/  (需同一 Wi-Fi)
```

然后在浏览器打开 `http://localhost:5184/` 即可。

其他启动方式（等价）：

```bash
cd D:\Kaoyan-Project\english
npm start          # 或 node server.js
```

**前提**：本机安装了 Node.js 18 或更高版本（<https://nodejs.org> 下载 LTS 版，一路下一步即可）。不需要 `npm install`，不需要数据库，不需要联网，不需要账号。

> 端口默认 `5184`，若被占用会自动顺延到 5185、5186……以启动窗口显示为准。四个子站各自独立端口，可同时运行互不干扰。

### 手机上怎么用

1. 手机与电脑连**同一个 Wi-Fi**；
2. 用手机浏览器打开启动窗口里的「手机访问」地址；
3. iPhone（Safari）：点底部分享按钮 → **添加到主屏幕**；Android（Chrome）：右上角菜单 → **安装应用 / 添加到主屏幕**；
4. 之后可全屏打开，Service Worker 会缓存应用外壳，断网也能打开已加载过的页面和本地数据。

> 不要直接双击 `index.html`（`file://` 协议）——页面用了 ES modules 与 PWA，必须通过 `启动.bat` 提供的 http 地址访问。

## 三、数据保存在哪里

- 所有学习进度、单词掌握记录、收藏、笔记、错题、译文、作文、考试成绩都保存在**当前浏览器的 localStorage**（键名 `ky-english-state-v1`）。
- 刷新页面、关闭浏览器、关机后数据**不会丢失**；Service Worker 提供离线可用能力。
- **不会上传**，也没有账号与跨设备同步。换浏览器、换设备、清除浏览器数据 / 无痕模式会导致数据不可见或丢失，所以请定期导出备份。
- 详见 [`docs/数据备份与恢复.md`](docs/数据备份与恢复.md)。

│   └── views.css              英语二专属视图样式

│   ├── app.js                 hash 路由 + 布局 + 全局事件委托
│   ├── store.js               版本化 localStorage 持久化 / 导出恢复
│   ├── words.js               词库索引（演示词条 + 资料词形 + 用户导入）
│   ├── srs.js                 间隔复习算法
│   ├── speech.js              浏览器原生发音
│   ├── ui.js / utils.js       通用组件与工具
│   └── views/                 12 个功能页面
├── data/                      【内容数据层：与代码分离】
│   ├── words.core.js          60 条演示词条（标注 AI 示例）
│   ├── words.corpus.js        2079 个真实词形（由 tools/extract-words.py 生成）

## 六、常见问题

| 问题 | 处理 |
|---|---|
| 双击 `index.html` 白屏 | 必须用 `启动.bat` 的 http 地址，ES modules 不支持 `file://` |
| `启动.bat` 提示未检测到 Node.js | 安装 Node.js LTS 后重新双击 |
| 发音没声音 | 检查设备静音/音量；iOS 必须由点击触发；在「设置 → 发音设置」换语音、点「测试朗读」；极少数浏览器无英语语音包时建议 Safari / Chrome |
| 数据好像没了 | 先确认没有换浏览器或使用无痕模式；在「数据与设置」看存储状态；定期导出备份是唯一可靠保险 |
| 端口被占用 | 服务器会自动换端口，看启动窗口显示的地址 |
| 想练真题 | 本站不含真题。用「设置 → 批量导入」导入你自己拥有使用权的材料，格式见 `docs/批量导入说明.md` |
